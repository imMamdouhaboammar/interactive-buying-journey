# Contributing to Interactive Buying Journey (IBJ)

Thank you for your interest in Interactive Buying Journey.

## External Contributions Policy

At this time, external code contributions, pull requests, and patches are **not accepted** until a formal contributor agreement is published by the project maintainers. Any unsolicited pull requests will be closed without merge.

## Reporting Issues

Issues and bug reports are welcome. When filing an issue:
1. Provide clear steps to reproduce the issue.
2. Include the relevant runtime environment, Go version, Node version, and browser if applicable.
3. Do not include any proprietary data, personal buyer information, API keys, or credentials in issue descriptions or logs.
