# Security Policy

## Reporting Security Vulnerabilities

We take the security of Interactive Buying Journey seriously.

If you discover a security vulnerability or potential security risk in this project, please **do not open a public issue or discuss it in public forums**.

Instead, please report the vulnerability privately through GitHub's Private Vulnerability Reporting feature:
1. Navigate to the repository's main page on GitHub: `https://github.com/imMamdouhaboammar/interactive-buying-journey`.
2. Click on the **Security** tab.
3. Select **Report a vulnerability** to open an advisory draft.

Your report will be reviewed confidentially. Please provide:
- A description of the vulnerability and its potential impact.
- Clear reproduction steps or proof-of-concept code.
- Any suggested mitigations.
